# Instruções do repositório

- Projeto de escritório de advocacia bancária (contra bancos). Responder em português do Brasil.
- Nunca inserir dados reais de clientes; use dados sintéticos (CPF 000.000.000-00, CNPJ 00.000.000/0001-00).
- Cálculo é feito por código; não calcular de cabeça.
- Citação jurídica só da `skills/legal-kb-revisional/references/kb.yaml`; marcar como pendente o que não foi conferido.
- Toda saída é rascunho para revisão de advogado.
- Rodar os testes (README) antes de commitar; o CI roda gitleaks.
